# Activity Bar

The Activity Bar widget shows one tab for each of your [activities](../settings/activities.md). Click a tab to switch to that activity. The tab of the current activity is highlighted.

Right-click the widget for two more entries:

- **Show Activity Manager** opens the activity manager, where you can add, stop and switch activities.
- **Configure Activities…** opens the [Activities](../settings/activities.md) module.
