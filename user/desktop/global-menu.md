# Global Menu

The Global Menu widget shows the menu bar of the window you're working in, inside a panel, instead of at the top of the window. It's the widget in the **Application Menu Bar** panel, which you can add from the desktop's **Add Panel** menu (see [Panels](panels.md)). You can also add it to any panel yourself.

When the active window has no menu to show, the widget shows its own name instead.

## Settings

Right-click the widget and choose **Configure Global Menu…** to change how it looks. The **Appearance** page has:

- **Use single button for application menu:** Shows the whole menu behind one button, which saves space in the panel.
- **Show full application menu:** Shows the menu bar with all of its menus side by side.
- **Show menus for apps on different screens:** Also shows the menu of the active window when that window is on another screen than the panel.
