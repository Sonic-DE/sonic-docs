# Network and file protocols

SonicDE applications reach files through small helper programs called KIO workers, one for each protocol. You can type a protocol's address in Ecco's location bar or in a file dialog, and most applications can open it.

## Local files and data

- [data](data.md): small documents inside the address itself
- [file](file.md): files on your computer
- [info](info.md): GNU Info documentation
- [man](man.md): manual pages
- [thumbnail](thumbnail.md): file previews

## Network

- [FTP](ftp.md): file transfer
- [fish](fish.md): another computer's files over SSH
- [http and https](http.md): web servers
- [NFS](nfs.md): shared file systems
- [SFTP](sftp.md): encrypted file transfer
- [SMB](smb.md): Windows and Samba shares
- [WebDAV](webdav.md): document management on web servers
