# tar

`tar` is an archiving program designed to store files in, and extract them from, an archive file known as a tarfile. A tarfile may be made on a tape drive, but it's also common to write one to a normal file.

The tar KIO worker can read these archives. It can't write to them.

See the `tar` man page.
