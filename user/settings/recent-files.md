# Recent Files

This module sets how long the history of opened files is kept, and clears tracking data.

**Keep history** sets how many months to keep it, or **Forever**.

The **Clear History** button can **Forget the last hour**, **Forget the last two hours**, **Forget a day** or **Forget everything**.

**Remember opened documents** sets which applications record them:

- **For all applications** stores all data.
- **Do not remember** turns off storing data.
- **Only for specific applications** lets you choose. Clicking an application in the list toggles its mode.

**Exclude applications not on the list** turns off tracking for all applications that aren't on the list.
