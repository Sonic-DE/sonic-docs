# Virtual Desktops

You can have several virtual desktops, each with its own windows.

Hover over a desktop in the list to reveal its **Rename** and **Remove** buttons.

**Add Desktop** adds a new one to the list.

**Rows** sets the number of rows the desktops are arranged in, which the Pager widget on your panel follows.

## Options

- **Navigation wraps around:** Moving past the edge of the desktops with the keyboard or a screen edge takes you to the opposite edge.
- **Show animation when switching:** Choose an animation from the list, or uncheck this to turn animations off. If the animation has settings, the button next to the list opens them.
- **Show on-screen display when switching:** Shows the desktop's name when you switch.
- **Show desktop layout indicators:** Also shows a small preview of the desktop layout, with the selected desktop indicated.

Scrolling the mouse wheel over an empty part of the desktop, or over the Pager widget, changes to the next virtual desktop in the direction you scrolled. You can change this in the Mouse Actions page of the desktop's settings, which you open from its context menu.
