# Date & Time

You can use this module to change the system date and time.

> [!NOTE]
> These settings affect the whole system, not just you, so changing them needs system administrator authorization.

## Date and Time

If you check **Set date and time automatically**, the time is kept in sync with network time servers (NTP) through the system's time service.

If you don't use a time server, you can set the date manually in the calendar. Use the controls at the bottom of the calendar to select the current date, enter the date in the edit box or select the week of the year from the drop-down box.

You set the time using the spin boxes at the bottom of the analog clock. You can also enter your value directly.

## Time Zone

To set a new time zone, select your area from the list. Use the filter box to find the area or region you want.
