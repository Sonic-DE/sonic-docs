# Application overview

This page lists applications and their accessibility status for screen readers. These notes come from older testing and haven't been checked again.

## The desktop

To get a more accessible menu, switch to the [Application Menu](../desktop/application-menu.md) and give it a keyboard shortcut. See [How to change the application launcher](../desktop/launchers.md#how-to-change-the-application-launcher).

## Terminal

SonicDE's terminal application.

- The shell doesn't implement an accessible text interface.
