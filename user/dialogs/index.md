# Common dialogs

SonicDE applications are built on the same frameworks, so many of their windows and menus are shared. Learn one, and you know it everywhere.

## Files

- [Open and Save dialogs](file-dialog.md): Find your way around the window that opens and saves files.
- [Properties dialog](properties.md): A file's or folder's details, permissions and checksums, and how an application launcher starts.
- [File operation dialogs](file-operations.md): Open With, renaming, what to do when a file already exists, and the delete confirmations.

## Settings and help

- [Common application menus](application-menus.md): The menu button, Find Action, and the shared Settings and Help menu items.
- [Shortcuts and toolbars in applications](shortcuts-and-toolbars.md): Change an application's keyboard shortcuts and toolbars.

## Other windows

- [Password dialogs](password-dialogs.md): Logging in to places, and choosing new passwords.
- [Check Spelling](check-spelling.md): Fix a document's spelling mistakes one by one.
- [Getting new add-ons](get-new-stuff.md): Install themes, wallpapers and other add-ons shared online.
- [Choosing a font](font-chooser.md): Pick a font, style, size and font features.
