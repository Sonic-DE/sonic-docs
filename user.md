# User Documentation

This tier is for people using Sonic-DE as their desktop: setting it up, finding your way
around and getting the most out of its applications.

The user documentation is still being written. Pages so far:

- [Ecco file manager](user/applications/ecco.md): browse, search and manage your files.
- [Terminal](user/applications/terminal.md): work on the command line with tabs, split views and
  profiles.
- [Screenies](user/applications/screenies.md): capture, annotate and share screenshots and screen
  recordings.
- [Clipboard](user/applications/clipboard.md): keep a history of what you copy and run actions on
  it.
- [Partition Manager](user/applications/partition-manager.md): manage disks, partitions and file
  systems.
- [System Log](user/applications/system-log.md): read and filter your computer's log files.
- [Info Center](user/applications/info-center.md): see a detailed overview of your system and its
  hardware.
- [System Monitor](user/applications/system-monitor.md): see what your computer is doing, and stop
  or slow down programs that misbehave.
- [SonicDE Menu Editor](user/applications/menu-editor.md): edit the menu of your application launchers.
- [Font Viewer](user/applications/font-viewer.md): view and install fonts.
- [Plasma Theme Explorer](user/applications/theme-explorer.md): look through a desktop theme's
  graphics and colors, and make your own theme.
- [Emoji Selector](user/applications/emoji-selector.md): find an emoji and copy it.
- [Print Queue](user/applications/print-queue.md): see what's waiting to print, and pause, cancel
  or move print jobs.
- [UVC Viewer](user/applications/uvc-viewer.md): watch a games console, set-top box or camera
  through a USB capture device.
- [Network Folder Wizard](user/applications/network-folder-wizard.md): add network folders to your
  desktop.
- [Running programs as another user](user/applications/run-as-another-user.md): run a program as
  another user with `kdesu`.
- [Authentication agent](user/applications/authentication-agent.md): how the desktop asks for your
  password when a program needs more privileges.
- [KDE Wallet](user/applications/kde-wallet.md): how your saved passwords are kept.
- [Vaults](user/applications/vaults.md): keep sensitive files in encrypted folders.
- [Welcome Center](user/applications/welcome-center.md): the tour that introduces SonicDE.
- [Crash Handler](user/applications/crash-handler.md): what happens when an application crashes,
  and how to report it.
- [Opening network files in any application](user/applications/network-files.md): how applications
  that only understand local files reach network locations.
- [System Settings](user/settings/index.md): configure your desktop from one place.
- [The SonicDE desktop](user/desktop.md): panels, widgets, launchers and search.
- [Network and file protocols](user/protocols/index.md): the addresses you can use in Ecco and file
  dialogs.
- [Desktop overview](user/desktop/overview.md): guides to panels, widgets, launchers, KRunner and
  more, with [desktop tips](user/desktop/tips.md), [more widgets](user/desktop/addon-widgets.md)
  and [more wallpaper types](user/desktop/more-wallpapers.md).
- [Common dialogs](user/dialogs/index.md): the windows and menus SonicDE applications share
  (Open/Save, Properties, Open With, rename, conflicts, shortcuts, toolbars, passwords,
  spelling, Get New, fonts).
- [SonicWin window manager](user/applications/sonicwin.md): what the window manager does, with
  tutorials.
- [Accessibility](user/accessibility/index.md): screen readers, visual aids and using the desktop
  from the keyboard.
- [Administration](user/administration/index.md): configuration files, environment variables, the
  startup sequence, caches, the [login manager](user/administration/login-manager.md) and
  [logs](user/administration/logs.md).
- Tutorials: [the Compose key](user/tutorials/compose-key.md),
  [keyboard actions](user/tutorials/keyboard.md), [custom shortcuts](user/tutorials/hotkeys.md),
  [transparency and blur](user/tutorials/transparency-and-blur.md),
  [pointer settings for large displays](user/tutorials/pointer-large-displays.md),
  [opening a console](user/tutorials/open-a-console.md),
  [changing the default settings](user/tutorials/modify-defaults.md),
  [changing the desktop language](user/tutorials/change-language.md) and
  [testing loose binding on your video card](user/tutorials/test-loose-binding.md).
- [Glossary](user/glossary.md): plain explanations of the terms you'll meet.
- [Mobile interface](user/mobile.md) and [TV interface](user/tv.md): SonicDE on tablets, phones and
  televisions, with their own [mobile settings](user/mobile-settings.md) and
  [TV settings](user/tv-settings.md).
