# User Documentation

This tier is for people using Sonic-DE as their desktop: setting it up, finding your way
around and getting the most out of its applications.

The user documentation is still being written. Pages so far:

- [Ecco file manager](user/applications/ecco.md): browse, search and manage your files.
- [Terminal](user/applications/terminal.md): work on the command line with tabs, split views and
  profiles.
- [Screenies](user/applications/screenies.md): capture, annotate and share screenshots and screen
  recordings.
- [Clipboard](user/applications/clipboard.md): keep a history of what you copy and run actions on
  it.
- [Partition Manager](user/applications/partition-manager.md): manage disks, partitions and file
  systems.
