# Ecco

Ecco is the file manager of SonicDE. Its source is in [`sonic-ecco`](https://github.com/Sonic-DE/sonic-ecco). Its command is currently `dolphin`.

- [Creating service menus](service-menus.md) adds your own actions to the context menu for files and folders.
