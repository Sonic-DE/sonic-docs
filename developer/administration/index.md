# System administration

After installing SonicDE, you can configure it to meet the needs of your users. This section has tutorials on administering SonicDE systems, from single users to deployment at large companies.

- [Kiosk](kiosk/index.md) restricts what users can change and do.
- [Menu favorites](menu.md) sets the default favorites in the application menus.
- [About page branding](about-branding.md) adds your details to the "About this System" page.
- [Portal pre-authorization](portal-permissions.md) lets applications use XDG portals without an interactive dialog.
