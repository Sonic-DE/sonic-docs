# Kiosk: configuration management for large deployments

The Kiosk framework makes it possible to restrict the capabilities of a SonicDE environment. It covers locking down configuration settings and restricting actions, URLs and settings modules.

- The [introduction](introduction.md) explains how it works.
- The [keys](keys.md) page lists what can be restricted.
