# Getting started with KXmlGui

This tutorial builds a small text editor with [KXmlGui](/docs/api/kxmlgui/kxmlgui-index) (`sonic-frameworks-xml-gui`) for the window and [KIO](/docs/api/kiocore/kio-index) (`sonic-frameworks-io`) for saving and loading files.

KXmlGui builds on QtWidgets and provides libraries for creating user interfaces with C++. QtWidgets is a mature technology with many ready-made components, strongly geared towards traditional desktop interfaces.

What you learn here introduces several of SonicDE's C++ libraries, and is useful for other tutorials too.

The steps:

1. [Hello World!](hello-world.md)
2. [Creating the main window](main-window.md)
3. [Using actions](using-actions.md)
4. [Saving and loading](saving-and-loading.md)
5. [Command line interface](command-line.md)
