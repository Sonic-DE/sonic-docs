# KQuickCharts Controls QML Types

Chart stuff.

- [AxisLabels](qml-org-kde-quickcharts-controls-axislabels.md): An item that uses a delegate to place axis labels on a chart.
- [GridLines](qml-org-kde-quickcharts-controls-gridlines.md): An item that renders a set of lines to make a grid for a chart.
- [Legend](qml-org-kde-quickcharts-controls-legend.md): A pre-made legend control that displays a legend for charts.
- [LegendDelegate](qml-org-kde-quickcharts-controls-legenddelegate.md): A delegate that can be used as part of a Legend.
- [LegendModel](qml-org-kde-quickcharts-controls-legendmodel.md): A model that extracts information from a chart that can be displayed as a legend.
- [LineChartControl](qml-org-kde-quickcharts-controls-linechartcontrol.md): A line chart with legend, grid and axis labels.
- [PieChartControl](qml-org-kde-quickcharts-controls-piechartcontrol.md): A pie chart with text in the middle.
