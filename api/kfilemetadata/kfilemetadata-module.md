## Classes {#classes}

- [KFileMetaData::EmbeddedImageData](kfilemetadata-embeddedimagedata.md): EmbeddedImageData defines enums for different image types that can be extracted from the metadata of e.g. music files.
- [KFileMetaData::ExtractionResult](kfilemetadata-extractionresult.md): The ExtractionResult class is where all the data extracted by the indexer is saved.
- [KFileMetaData::Extractor](kfilemetadata-extractor.md): The Extractor class is used to extract data from a file.
- [KFileMetaData::ExtractorCollection](kfilemetadata-extractorcollection.md): The ExtractorCollection is a helper class which internally loads all the extractor plugins.
- [KFileMetaData::ExtractorPlugin](kfilemetadata-extractorplugin.md): The ExtractorPlugin is the base class for all file metadata extractors.
- [KFileMetaData::PropertyInfo](kfilemetadata-propertyinfo.md): The PropertyInfo class can be used to obtain extra information about any property.
- [KFileMetaData::SimpleExtractionResult](kfilemetadata-simpleextractionresult.md): A simple ExtractionResult implementation which stores all the data in memory.
- [KFileMetaData::TypeInfo](kfilemetadata-typeinfo.md): The TypeInfo class can be used to obtain a rough type classification for a file.
- [KFileMetaData::UserMetaData](kfilemetadata-usermetadata.md): The UserMetaData class can be used to read and set user meta data of files.
- [KFileMetaData::WriteData](kfilemetadata-writedata.md): The WriteData class stores all the data to be written to a file.
- [KFileMetaData::Writer](kfilemetadata-writer.md): The Writer class is used to write data to a file.
- [KFileMetaData::WriterCollection](kfilemetadata-writercollection.md): The WriterCollection is a helper class which internally loads all the writer plugins.
- [KFileMetaData::WriterPlugin](kfilemetadata-writerplugin.md): The WriterPlugin is the base class for all file metadata writers.
