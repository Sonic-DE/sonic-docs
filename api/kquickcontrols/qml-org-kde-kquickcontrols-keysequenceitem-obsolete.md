# Obsolete Members for KeySequenceItem

**The following members of QML type [KeySequenceItem](qml-org-kde-kquickcontrols-keysequenceitem.md) are deprecated.** We strongly advise against using them in new code.

## Properties

- [\[deprecated in 6.16\] modifierOnlyAllowed : bool](#modifierOnlyAllowed-prop)
- [\[deprecated in 6.16\] modifierlessAllowed : bool](#modifierlessAllowed-prop)

## Obsolete Property Documentation {#obsolete-property-documentation}

### \[deprecated in 6.16\] modifierOnlyAllowed : bool {#modifierOnlyAllowed-prop}

This property is deprecated since org.kde.kquickcontrols 6.16. We strongly advise against using it in new code.

Use patterns instead.

### \[deprecated in 6.16\] modifierlessAllowed : bool {#modifierlessAllowed-prop}

This property is deprecated since org.kde.kquickcontrols 6.16. We strongly advise against using it in new code.

Use patterns instead.

## Obsolete Signal Documentation {#obsolete-signal-documentation}

### \[deprecated\] captureFinished() {#captureFinished-signal}

This signal is deprecated. We strongly advise against using it in new code.

Emitted after the user introduces a new key sequence.

Use [keySequenceModified](qml-org-kde-kquickcontrols-keysequenceitem.md#keySequenceModified-signal)() instead.

> **Note:** The corresponding handler is `onCaptureFinished`.
