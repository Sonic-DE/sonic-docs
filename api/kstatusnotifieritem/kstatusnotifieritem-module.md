## Detailed Description {#details}

The [KStatusNotifierItem](kstatusnotifieritem-module.md) class makes use of the [StatusNotifierItem specification](https://www.freedesktop.org/wiki/Specifications/StatusNotifierItem/) to expose an implementation-dependent tray icon over D-Bus.
