# Kirigami Addons DateAndTime QML Types

QML types for selecting dates and times.

Use [DatePopup](qml-datepopup.md) to select a date, or [TimePopup](qml-org-kde-kirigamiaddons-dateandtime-timepopup.md) to select a time in a dialog. [TimePicker](qml-timepicker.md) provides a time selection control that can also be embedded in another interface.

- [TimePopup](qml-org-kde-kirigamiaddons-dateandtime-timepopup.md): A dialog for selecting a time.
