# Obsolete Members for DatePopup

**The following members of QML type [DatePopup](qml-datepopup.md) are deprecated.** We strongly advise against using them in new code.

## Obsolete Signal Documentation {#obsolete-signal-documentation}

### \[deprecated\] cancelled() {#cancelled-signal}

This signal is deprecated. We strongly advise against using it in new code.

Emitted when the user cancels the popup. Use rejected instead.

> **Note:** The corresponding handler is `onCancelled`.
