# Kirigami Addons Sounds QML Types

QML types for listing and selecting notification sounds and ringtones.

[SoundsModel](qml-org-kde-kirigamiaddons-sounds-soundsmodel.md) lists available sounds, and [SoundsPicker](qml-org-kde-kirigamiaddons-sounds-soundspicker.md) lets users select and preview one. Both types are deprecated since 1.14.1.
