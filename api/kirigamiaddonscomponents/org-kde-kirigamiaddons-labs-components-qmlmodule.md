# Kirigami Addons Components (Labs) QML Types

Additional components for specialized interfaces.

The labs module contains additional components for specialized interfaces, including media viewing. Import it separately when using those types:

```qml
import org.kde.kirigamiaddons.labs.components as LabsComponents
```

- [AbstractMaximizeComponent](qml-org-kde-kirigamiaddons-labs-components-abstractmaximizecomponent.md): A popup that covers the entire window to show a content item.
- [AlbumMaximizeComponent](qml-org-kde-kirigamiaddons-labs-components-albummaximizecomponent.md): A popup that covers the entire window to show an album of one or more media items.
- [AlbumModelItem](qml-org-kde-kirigamiaddons-labs-components-albummodelitem.md): An object container for defining content items to show in an AlbumMaximizeComponent.
- [DownloadAction](qml-org-kde-kirigamiaddons-labs-components-downloadaction.md): An action for with bindings for managing the download of a piece of media.
- [ImageMaximizeDelegate](qml-org-kde-kirigamiaddons-labs-components-imagemaximizedelegate.md)
- [VideoMaximizeDelegate](qml-org-kde-kirigamiaddons-labs-components-videomaximizedelegate.md)
