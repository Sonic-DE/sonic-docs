# Kirigami Addons Components Templates

Shared API and behavior for stylable components.

Applications should normally use org.kde.kirigamiaddons.components. This module provides the bases for its style implementations.

- [BottomDrawer](qml-org-kde-kirigamiaddons-components-templates-bottomdrawer.md): Shared content, header layout and behavior for bottom drawers.
- [DoubleFloatingButton](qml-org-kde-kirigamiaddons-components-templates-doublefloatingbutton.md): Shared actions, clickable margins and surface for paired floating buttons.
- [FloatingButton](qml-org-kde-kirigamiaddons-components-templates-floatingbutton.md): Shared API and clickable margins for floating buttons.
- [FloatingToolBar](qml-org-kde-kirigamiaddons-components-templates-floatingtoolbar.md): Shared content sizing for floating toolbars.
- [MessageDialog](qml-org-kde-kirigamiaddons-components-templates-messagedialog.md): A message dialog with success, warning, error, and information styles.
- [RadioSelector](qml-org-kde-kirigamiaddons-components-templates-radioselector.md): Shared actions, exclusive selection and layout for radio selectors.
- [SegmentedButton](qml-org-kde-kirigamiaddons-components-templates-segmentedbutton.md): Shared actions and layout for segmented buttons.
