# Obsolete Members for SearchPopupField

**The following members of QML type [SearchPopupField](qml-org-kde-kirigamiaddons-components-searchpopupfield.md) are deprecated.** We strongly advise against using them in new code.

## Properties

- [\[deprecated\] spaceAvailableLeft : bool](#spaceAvailableLeft-prop)
- [\[deprecated\] spaceAvailableRight : bool](#spaceAvailableRight-prop)

## Obsolete Property Documentation {#obsolete-property-documentation}

### \[deprecated\] spaceAvailableLeft : bool {#spaceAvailableLeft-prop}

This property is deprecated. We strongly advise against using it in new code.

This property holds whether there is space available on the left.

This is used by the left shadow.

Was not really used by anything.

### \[deprecated\] spaceAvailableRight : bool {#spaceAvailableRight-prop}

This property is deprecated. We strongly advise against using it in new code.

This property holds whether there is space available on the left.

This is used by the right shadow.

Was not really used by anything.
