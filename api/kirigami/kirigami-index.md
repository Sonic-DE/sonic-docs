# Kirigami

Components for Convergent Applications.

Kirigami is a set of [QtQuick](https://doc.qt.io/qt-6/qtquick-index.html) components for building adaptable UIs based on [QtQuick Controls 2](https://doc.qt.io/qt-6/qtquickcontrols-index.html).

Its goal is to enable creation of convergent applications that look and feel great on mobile as well as desktop devices and follow the [KDE Human Interface Guidelines](https://develop.kde.org/hig) while being easy to use and not adding many dependencies.

Kirigami works on a variety of platforms, such as [Plasma Mobile](https://plasma-mobile.org/), Desktop Linux, Android, MacOS, and Windows.

A tutorial for Kirigami is available on the [KDE Developer platform](https://develop.kde.org/docs/getting-started/kirigami/).

A list of additional QML learning resources is available in the [Community Wiki](https://community.kde.org/Get_Involved/development/Learn#QtQuick/QML). If you are not familiar with QML at all, the [QML book](https://www.qt.io/product/qt6/qml-book) should be a good head start.

If you have any questions about Kirigami, feel free to drop by the [Kirigami group on Matrix](https://go.kde.org/matrix/#/#kirigami:kde.org).
