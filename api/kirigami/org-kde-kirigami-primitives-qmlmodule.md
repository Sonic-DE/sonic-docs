# Kirigami Primitives QML Types

Kirigami Primitives.

- [AlignedSize](qml-org-kde-kirigami-primitives-alignedsize.md): An attached property that aligns a size on the physical pixel grid.
- [Icon](qml-org-kde-kirigami-primitives-icon.md): Class for rendering an icon supporting many different sources.
- [IconPropertiesGroup](qml-org-kde-kirigami-primitives-iconpropertiesgroup.md): An object to be used as a grouped property compatible with QtQuickControls "icon" grouped property.
- [MnemonicData](qml-org-kde-kirigami-primitives-mnemonicdata.md): An attached property used to calculate automated keyboard sequences to trigger actions based upon their text.
- [ScenePosition](qml-org-kde-kirigami-primitives-sceneposition.md): An attached property that contains the information about the scene position of the item.
- [Separator](qml-org-kde-kirigami-primitives-separator.md): A visual separator.
- [ShadowedImage](qml-org-kde-kirigami-primitives-shadowedimage.md): An image with a shadow.
- [ShadowedRectangle](qml-org-kde-kirigami-primitives-shadowedrectangle.md): A rectangle with a shadow behind it.
- [ShadowedTexture](qml-org-kde-kirigami-primitives-shadowedtexture.md): A rectangle with a shadow, using a Item as texture.
- [ToolsAreaBackground](qml-org-kde-kirigami-primitives-toolsareabackground.md): The background of a toolbar or main menu bar, joining the window's tools area when it is part of the stack of bars at the window's top.
