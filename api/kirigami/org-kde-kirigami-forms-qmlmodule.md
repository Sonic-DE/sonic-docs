# Kirigami Forms QML Types

Kirigami Forms.

- [Form](qml-org-kde-kirigami-forms-form.md): The base class for Form conforming to the Kirigami Human Interface Guidelines.
- [FormAction](qml-org-kde-kirigami-forms-formaction.md): A specialized FormEntry for a big clickable action.
- [FormAlignmentGroup](qml-org-kde-kirigami-forms-formalignmentgroup.md): A group of forms that should be perfectly aligned with each other.
- [FormEntry](qml-org-kde-kirigami-forms-formentry.md): The base type of all Form entries.
- [FormGroup](qml-org-kde-kirigami-forms-formgroup.md): The container class that identifies a container of related controls in a form.
- [FormSeparator](qml-org-kde-kirigami-forms-formseparator.md): An item used to separate entries within a FormGroup.
