# Kirigami Dialogs QML Types

Kirigami Dialogs.

- [Dialog](qml-org-kde-kirigami-dialogs-dialog.md): Popup dialog that is used for short tasks and user interaction.
- [DialogHeader](qml-org-kde-kirigami-dialogs-dialogheader.md): Base for a header, to be used as the header: item of a Dialog.
- [DialogHeaderTopContent](qml-org-kde-kirigami-dialogs-dialogheadertopcontent.md): Standard top content for a Dialog, including header text and an optional close button.
- [MenuDialog](qml-org-kde-kirigami-dialogs-menudialog.md): A dialog that prompts users with a context menu, with list items that perform actions.
- [PromptDialog](qml-org-kde-kirigami-dialogs-promptdialog.md): A simple dialog to quickly prompt a user with information, and possibly perform an action.
- [SearchDialog](qml-org-kde-kirigami-dialogs-searchdialog.md): A dialog to let's you do a global search across your applications documents, chat rooms and more.
