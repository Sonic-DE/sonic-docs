# Kirigami QML Types

Kirigami Types.

- [AboutItem](qml-org-kde-kirigami-aboutitem.md): An about item that displays the about data.
- [AboutPage](qml-org-kde-kirigami-aboutpage.md): An "About" page that is ready to integrate in a Kirigami app.
- [AbstractApplicationHeader](qml-org-kde-kirigami-abstractapplicationheader.md): An item that can be used as a title for the application.
- [AbstractApplicationItem](qml-org-kde-kirigami-abstractapplicationitem.md): An item that provides the features of AbstractApplicationWindow without the window itself.
- [AbstractApplicationWindow](qml-org-kde-kirigami-abstractapplicationwindow.md): A window that provides some basic features needed for all apps.
- [AbstractCard](qml-org-kde-kirigami-abstractcard.md): The base item for all kinds of cards.
- [Action](qml-org-kde-kirigami-action.md): An item that represents an abstract Action.
- [ActionTextField](qml-org-kde-kirigami-actiontextfield.md): An advanced control to create custom textfields with inline buttons.
- [ActionToolBar](qml-org-kde-kirigami-actiontoolbar.md): A toolbar built from a list of actions.
- [ApplicationItem](qml-org-kde-kirigami-applicationitem.md): An item that provides the features of ApplicationWindow without the window itself.
- [ApplicationWindow](qml-org-kde-kirigami-applicationwindow.md): A window that provides some basic features needed for all apps.
- [Badge](qml-org-kde-kirigami-badge.md): A badge with a colored background.
- [Card](qml-org-kde-kirigami-card.md): Card with a standard layout.
- [CardsLayout](qml-org-kde-kirigami-cardslayout.md): A GridLayout optimized for showing one or two columns of cards, depending on the available space.
- [CardsListView](qml-org-kde-kirigami-cardslistview.md): A ListView that can have AbstractCard as its delegate.
- [Chip](qml-org-kde-kirigami-chip.md): A compact element that represents an attribute, action, or filter.
- [ContextDrawer](qml-org-kde-kirigami-contextdrawer.md): A specialized type of drawer that will show a list of actions relevant to the application's current page.
- [ContextualHelpButton](qml-org-kde-kirigami-contextualhelpbutton.md): An inline help button that shows a tooltip when clicked.
- [FlexColumn](qml-org-kde-kirigami-flexcolumn.md): FlexColumn is a column that grows in width to a fixed cap.
- [GlobalDrawer](qml-org-kde-kirigami-globaldrawer.md): A specialized form of the Drawer intended for showing an application's always-available global actions.
- [Heading](qml-org-kde-kirigami-heading.md): A pre-formatted label used for titles and section headers.
- [ImageColors](qml-org-kde-kirigami-imagecolors.md): Extracts the dominant colors from an element or an image and exports it to a color palette.
- [InlineMessage](qml-org-kde-kirigami-inlinemessage.md): An inline message item with support for associated actions.
- [InlineViewHeader](qml-org-kde-kirigami-inlineviewheader.md): A fancy inline view header showing a title and optional actions.
- [LinkButton](qml-org-kde-kirigami-linkbutton.md): A button that looks like a link.
- [ListItemDragHandle](qml-org-kde-kirigami-listitemdraghandle.md): A handle to reorder items in a view.
- [ListSectionHeader](qml-org-kde-kirigami-listsectionheader.md): A section delegate for the primitive ListView component.
- [LoadingPlaceholder](qml-org-kde-kirigami-loadingplaceholder.md): A placeholder for loading pages.
- [NavigationTabBar](qml-org-kde-kirigami-navigationtabbar.md): Page navigation tab-bar, used as an alternative to sidebars for 3-5 elements. A NavigationTabBar can be both used as a footer or a header for a page. It can be combined with secondary toolbars above (if in the footer) to provide page actions.
- [NavigationTabButton](qml-org-kde-kirigami-navigationtabbutton.md): Navigation buttons to be used for the NavigationTabBar component.
- [OverlayDrawer](qml-org-kde-kirigami-overlaydrawer.md): A Drawer used to expose additional UI elements needed for small secondary tasks for which the main UI elements are not needed.
- [OverlaySheet](qml-org-kde-kirigami-overlaysheet.md): An overlay sheet that covers the current Page content.
- [OverlayZStacking](qml-org-kde-kirigami-overlayzstacking.md): An attached property that manages z-index for stacking overlays relative to each other.
- [Page](qml-org-kde-kirigami-page.md): A container for all the app pages.
- [PagePool](qml-org-kde-kirigami-pagepool.md): A pool of Page items.
- [PagePoolAction](qml-org-kde-kirigami-pagepoolaction.md): An action used to load Pages coming from a common PagePool in a PageRow or QtQuickControls2 StackView.
- [PageRow](qml-org-kde-kirigami-pagerow.md): A row-based navigation model that can be used with a set of interlinked information pages.
- [PasswordField](qml-org-kde-kirigami-passwordfield.md): This is a standard password text field.
- [PlaceholderMessage](qml-org-kde-kirigami-placeholdermessage.md): A placeholder message indicating that a view is empty.
- [ScrollablePage](qml-org-kde-kirigami-scrollablepage.md): ScrollablePage is a Page that holds scrollable content, such as a ListView.
- [SearchField](qml-org-kde-kirigami-searchfield.md): Standard TextField following the KDE HIG.
- [SelectableLabel](qml-org-kde-kirigami-selectablelabel.md): This is a label which supports text selection.
- [SpellCheck](qml-org-kde-kirigami-spellcheck.md): This attached property contains hints for spell checker.
- [UrlButton](qml-org-kde-kirigami-urlbutton.md): A link to a URL or other remote resource.
- [WheelEvent](qml-org-kde-kirigami-wheelevent.md): Describes the mouse wheel event.
- [WheelHandler](qml-org-kde-kirigami-wheelhandler.md): Handles scrolling for a Flickable and 2 attached ScrollBars.
- [imageColorsPaletteSwatch](qml-imagecolorspaletteswatch.md)
