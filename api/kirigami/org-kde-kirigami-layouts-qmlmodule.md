# Kirigami Layouts QML Types

Kirigami Layouts.

- [ColumnView](qml-org-kde-kirigami-layouts-columnview.md): A container that lays out items horizontally in a row.
- [DisplayHint](qml-org-kde-kirigami-layouts-displayhint.md): Hints for implementations using Actions indicating preferences about how to display the action.
- [FormData](qml-org-kde-kirigami-layouts-formdata.md): An attached property with information for decorating a FormLayout.
- [FormLayout](qml-org-kde-kirigami-layouts-formlayout.md): The base class for Form layouts conforming to the Kirigami Human Interface Guidelines.
- [HeaderFooterLayout](qml-org-kde-kirigami-layouts-headerfooterlayout.md): Replicates a little part of what Page does.
- [Padding](qml-org-kde-kirigami-layouts-padding.md): This item simply adds an external padding to contentItem's size.
- [PageStack](qml-org-kde-kirigami-layouts-pagestack.md): This attached property makes possible to access from anywhere the page stack this page was pushed into.
- [SizeGroup](qml-org-kde-kirigami-layouts-sizegroup.md): SizeGroup is a utility object that makes groups of items request the same size.
- [ToolBarLayout](qml-org-kde-kirigami-layouts-toolbarlayout.md): An item that creates delegates for actions and lays them out in a row.
