# SettingAction QML Type

[SettingAction](qml-org-kde-kirigamiaddons-settings-settingaction.md) defines a settings page, and is typically used by a [CategorizedSettings](qml-org-kde-kirigamiaddons-settings-categorizedsettings.md) object. Since 1.3.0, use [ConfigurationModule](qml-org-kde-kirigamiaddons-settings-configurationmodule.md) instead. **This type is deprecated. We strongly advise against using it in new code.** [More...](#details)

- Import Statement: import org.kde.kirigamiaddons.settings
- Inherits: [PagePoolAction](../kirigami/qml-org-kde-kirigami-pagepoolaction.md)
- Status: Deprecated

**This type is deprecated. We strongly advise against using it in new code.**

## Property Documentation {#property-documentation}

### \[required\] actionName : string {#actionName-prop}

The name of the action for when it needs to be referenced.

Primary use case if for setting a default page in CategorizedSettings.
