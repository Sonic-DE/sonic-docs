# Plasmoid QML Types

Plasma Stuff.

- [Containment](qml-org-kde-plasma-plasmoid-containment.md): The base class for plugins that provide backgrounds and applet grouping containers.
- [ContainmentItem](qml-org-kde-plasma-plasmoid-containmentitem.md): This class is exposed to containments QML as the attached property Plasmoid.
- [Plasmoid](qml-org-kde-plasma-plasmoid-plasmoid.md): Common attached properties for plasmoids.
- [PlasmoidItem](qml-org-kde-plasma-plasmoid-plasmoiditem.md)
- [WallpaperItem](qml-org-kde-plasma-plasmoid-wallpaperitem.md): This class is exposed to wallpapers as the WallpaperItem root qml item.
