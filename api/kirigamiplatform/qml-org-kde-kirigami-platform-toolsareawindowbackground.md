# ToolsAreaWindowBackground QML Type

An application window's background with the tools area left out. [More...](#details)

- Import Statement: import org.kde.kirigami.platform

## Detailed Description {#details}

Fills its window with [color](qml-org-kde-kirigami-platform-toolsareawindowbackground.md#color-prop) except the window's ToolsAreaRegions, as Silver paints widget main windows: with a translucent tools area the window color is transparent and the tools area shows only its own background.

## Property Documentation {#property-documentation}

### color : color {#color-prop}
