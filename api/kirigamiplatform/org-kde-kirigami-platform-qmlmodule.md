# Kirigami Platform QML Types

Platform Integration Components.

- [ColorUtils](qml-org-kde-kirigami-platform-colorutils.md): Utilities for processing items to obtain colors and information useful for UIs that need to adjust to variable elements.
- [InputMethod](qml-org-kde-kirigami-platform-inputmethod.md): This exposes information about the current used input method.
- [Settings](qml-org-kde-kirigami-platform-settings.md): Provides global kirigami settings about the current device setup under the singleton "Settings".
- [StyleHints](qml-org-kde-kirigami-platform-stylehints.md): An attached type that contains hints for styles to use.
- [Theme](qml-org-kde-kirigami-platform-theme.md): This class is the base for color management in Kirigami, different platforms can reimplement this class to integrate with system platform colors of a given platform.
- [ToolsArea](qml-org-kde-kirigami-platform-toolsarea.md): How the window's tools area is drawn: the toolbars and main menu bar at the top of a window, under the title bar.
- [ToolsAreaRegion](qml-org-kde-kirigami-platform-toolsarearegion.md): Marks its area as part of the window's tools area, for blur behind it.
- [ToolsAreaWindowBackground](qml-org-kde-kirigami-platform-toolsareawindowbackground.md): An application window's background with the tools area left out.
- [Units](qml-org-kde-kirigami-platform-units.md): A set of values to define semantically sizes and durations.
