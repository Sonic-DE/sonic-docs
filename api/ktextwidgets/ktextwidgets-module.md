# KTextWidgets C++ Classes

[KTextWidgets](ktextwidgets-module.md) is a collection of text editing widgets. [More...](#details)

## Classes {#classes}

- [KFind](kfind.md): A generic implementation of the "find" function.
- [KFindDialog](kfinddialog.md): A generic "find" dialog.
- [KReplace](kreplace.md): A generic implementation of the "replace" function.
- [KReplaceDialog](kreplacedialog.md): A generic "replace" dialog.
- [KRichTextEdit](krichtextedit.md): A KTextEdit that supports both rich text and plain text modes.
- [KRichTextWidget](krichtextwidget.md): A KRichTextEdit with common actions.
- [KTextEdit](ktextedit.md): A KDE'ified QTextEdit.

## Detailed Description {#details}

[KTextWidgets](ktextwidgets-module.md) provides widgets for displaying and editing text. It supports rich text as well as plain text.
