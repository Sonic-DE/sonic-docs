# KCompletion C++ Classes

Text completion helpers and widgets. [More...](#details)

## Classes {#classes}

- [KComboBox](kcombobox.md): A combo box with completion support.
- [KCompletion](kcompletion.md): A generic class for completing QStrings.
- [KCompletionBase](kcompletionbase.md): An abstract base class for adding a completion feature into widgets.
- [KCompletionBox](kcompletionbox.md): A helper widget for "completion-widgets" (KLineEdit, KComboBox)).
- [KCompletionMatches](kcompletionmatches.md): List for keeping matches returned from KCompletion.
- [KEmailValidator](kemailvalidator.md): An input validator that checks for valid email addresses.
- [KHistoryComboBox](khistorycombobox.md): A combobox for offering a history and completion.
- [KLineEdit](klineedit.md): An enhanced QLineEdit widget for inputting text.
- [KSortableItem](ksortableitem.md): KSortableItem is a QPair that provides several operators for sorting.
- [KSortableList](ksortablelist.md): KSortableList is a QList which associates a key with each item in the list. This key is used for sorting when calling sort().
