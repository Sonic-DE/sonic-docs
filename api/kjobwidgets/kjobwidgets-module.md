- [KNotificationJobUiDelegate](knotificationjobuidelegate.md): A UI delegate using KNotification for interaction (showing errors and warnings).

- [KUiServerV2JobTracker](kuiserverv2jobtracker.md): The interface to implement to track the progresses of a job.
- [KWidgetJobTracker](kwidgetjobtracker.md): This class implements a job tracker with a widget suited for use as a progress dialog.
