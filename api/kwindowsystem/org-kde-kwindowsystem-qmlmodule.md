# KWindowSystem QML Types

Access to the windowing system.

- [KWindowSystem](qml-org-kde-kwindowsystem-kwindowsystem.md): Convenience access to certain properties and features of window systems.
- [KX11Extras](qml-org-kde-kwindowsystem-kx11extras.md): A collection of functions to obtain information from and manipulate X11 windows.
