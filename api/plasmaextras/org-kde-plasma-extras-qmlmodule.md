# Plasma Extras QML Types

Plasma Extra Stuff.

- [ActionTextField](qml-org-kde-plasma-extras-actiontextfield.md): This is advanced textfield. It is recommended to use this class when there is a need to create a create a textfield with action buttons (e.g a clear action).
- [BasicPlasmoidHeading](qml-org-kde-plasma-extras-basicplasmoidheading.md): A standard basic header for plasmoids which has title, a config button and a popup menu with all extra plasmoid actions.
- [DescriptiveLabel](qml-org-kde-plasma-extras-descriptivelabel.md): This is a descriptive label which uses the plasma theme.
- [ExpandableListItem](qml-org-kde-plasma-extras-expandablelistitem.md): A list item that expands when clicked to show additional actions and/or a custom view.
- [Heading](qml-org-kde-plasma-extras-heading.md): A heading label used for subsections of texts.
- [Highlight](qml-org-kde-plasma-extras-highlight.md): Highlight for a list or grid item.
- [ListItem](qml-org-kde-plasma-extras-listitem.md)
- [ListSectionHeader](qml-org-kde-plasma-extras-listsectionheader.md): A section delegate for the primitive ListView component.
- [ModelContextMenu](qml-org-kde-plasma-extras-modelcontextmenu.md): A ModelContextMenu creates a context menu with items populated from a model or a QList\<QAction\*\>.
- [PasswordField](qml-org-kde-plasma-extras-passwordfield.md): This is a standard password text field.
- [PlaceholderMessage](qml-org-kde-plasma-extras-placeholdermessage.md): A placeholder message indicating that a list view is empty.
- [PlasmoidHeading](qml-org-kde-plasma-extras-plasmoidheading.md): Item to be used as a header or footer in plasmoids.
- [Representation](qml-org-kde-plasma-extras-representation.md): Item to be used as root item for representations (full and compact) of plasmoids.
- [SearchField](qml-org-kde-plasma-extras-searchfield.md): This is a standard textfield following KDE HIG. Using Ctrl+F as focus sequence and "Search…" as placeholder text.
- [ShadowedLabel](qml-org-kde-plasma-extras-shadowedlabel.md): White text label with a black shadow behind it.
