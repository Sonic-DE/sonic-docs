# BasicPlasmoidHeading QML Type

A standard basic header for plasmoids which has title, a config button and a popup menu with all extra plasmoid actions. [More...](#details)

- Import Statement: import org.kde.plasma.extras
- Inherits: [PlasmoidHeading](qml-org-kde-plasma-extras-plasmoidheading.md)

## Detailed Description {#details}

By default, it will be invisible when the plasmoid is in the system tray, as it provides a replacement header with the same features

## Property Documentation {#property-documentation}

### \[default\] extraControls : QtObject {#extraControls-prop}

Any extra control and button that may be inserted in the heading
