# KCMUtils Core C++ Classes

Utilities for KDE System Settings modules.

## Classes {#classes}

- [KAbstractConfigModule](kabstractconfigmodule.md): Base class for QML and QWidgets config modules.
- [KCModuleData](kcmoduledata.md): A base class that offers information about a KCModule state.
- [KPluginModel](kpluginmodel.md): A model that provides a list of available plugins and allows to disable/enable them.
