# Obsolete Members for AbstractKCM

**The following members of QML type [AbstractKCM](qml-org-kde-kcmutils-abstractkcm.md) are deprecated.** We strongly advise against using them in new code.

## Properties

- [\[default: false, deprecated\] extraFooterTopPadding : bool](#extraFooterTopPadding-prop)

## Obsolete Property Documentation {#obsolete-property-documentation}

### \[default: false, deprecated\] extraFooterTopPadding : bool {#extraFooterTopPadding-prop}

This property is deprecated. We strongly advise against using it in new code.

\* Use [forceFooterSeparator](qml-org-kde-kcmutils-abstractkcm.md#forceFooterSeparator-prop) and/or [footerPaddingEnabled](qml-org-kde-kcmutils-abstractkcm.md#footerPaddingEnabled-prop) instead

Whether the footer should have extra space and a separator line drawn above it.

Set this to true in a KCM with a custom footer and a [ListView](https://doc.qt.io/qt-6/qml-qtquick-listview.html) immediately above it.
