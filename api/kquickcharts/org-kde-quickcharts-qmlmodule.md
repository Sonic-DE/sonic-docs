# KQuickCharts QML Types

Chart stuff.

- [ArraySource](qml-org-kde-quickcharts-arraysource.md): A data source that provides entries of an array as data.
- [BarChart](qml-org-kde-quickcharts-barchart.md): An item to render a bar chart.
- [Chart](qml-org-kde-quickcharts-chart.md): Abstract base class for all charts.
- [ChartAxisSource](qml-org-kde-quickcharts-chartaxissource.md): A data source that provides values from a chart's axis as data.
- [ChartDataSource](qml-org-kde-quickcharts-chartdatasource.md): Abstract base class for data sources.
- [ColorGradientSource](qml-org-kde-quickcharts-colorgradientsource.md): A data source that provides a hue-shifted color as data.
- [HistoryProxySource](qml-org-kde-quickcharts-historyproxysource.md): A data source that provides a history of a single item of a different data source.
- [LineChart](qml-org-kde-quickcharts-linechart.md): A line chart.
- [MapProxySource](qml-org-kde-quickcharts-mapproxysource.md): A source that uses the values of another source to produce values from a map.
- [ModelSource](qml-org-kde-quickcharts-modelsource.md): A data source that reads data from a QAbstractItemModel.
- [PieChart](qml-org-kde-quickcharts-piechart.md): An item to render a pie chart.
- [SingleValueSource](qml-org-kde-quickcharts-singlevaluesource.md): A data source that provides a single value as data.
- [XYChart](qml-org-kde-quickcharts-xychart.md): A base class for Charts that are based on an X/Y grid.
