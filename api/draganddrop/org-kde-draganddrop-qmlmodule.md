# DragAndDrop QML Types

QML helpers for Drag and Drop.

- [DragArea](qml-org-kde-draganddrop-dragarea.md)
- [DragDropEvent](qml-org-kde-draganddrop-dragdropevent.md)
- [DropArea](qml-org-kde-draganddrop-droparea.md)
- [MimeData](qml-org-kde-draganddrop-mimedata.md): This is a wrapper class around QMimeData with a few extensions to provide better support for in-qml drag & drops.
- [MimeDataWrapper](qml-org-kde-draganddrop-mimedatawrapper.md): Exposes a const QMimeData instance.
