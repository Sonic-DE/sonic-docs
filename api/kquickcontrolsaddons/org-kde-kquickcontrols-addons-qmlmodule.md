# KQuickControlsAddons QML Types

Extensions to Qt Quick Controls.

- [Clipboard](qml-org-kde-kquickcontrols-addons-clipboard.md): Wrapper for QClipboard.
- [KDeclarativeMouseEvent](qml-org-kde-kquickcontrols-addons-kdeclarativemouseevent.md): This item spies on mouse events from all child objects including child MouseAreas regardless of whether the child MouseArea propagates events. It does not accept the event.

- [MouseEventListener](qml-org-kde-kquickcontrols-addons-mouseeventlistener.md)
- [QImageItem](qml-org-kde-kquickcontrols-addons-qimageitem.md)
- [QPixMapItem](qml-org-kde-kquickcontrols-addons-qpixmapitem.md)
