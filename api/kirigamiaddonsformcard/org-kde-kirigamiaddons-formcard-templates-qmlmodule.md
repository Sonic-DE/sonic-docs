# Kirigami Addons FormCard Templates

Shared layout and geometry for [FormCard](qml-org-kde-kirigamiaddons-formcard-templates-formcard.md) style implementations.

Applications should normally use org.kde.kirigamiaddons.formcard. This module provides the bases for its default and Material appearances.

- [FormCard](qml-org-kde-kirigamiaddons-formcard-templates-formcard.md): A single card that follows a form style.
- [FormCardDialog](qml-org-kde-kirigamiaddons-formcard-templates-formcarddialog.md): A dialog designed to use FormCard delegates as its content.
- [FormDelegateBackground](qml-org-kde-kirigamiaddons-formcard-templates-formdelegatebackground.md): Shared corner geometry for Form delegate backgrounds.
- [FormGridContainer](qml-org-kde-kirigamiaddons-formcard-templates-formgridcontainer.md): This component render a grid of small cards.
- [FormHeader](qml-org-kde-kirigamiaddons-formcard-templates-formheader.md): A header item for a form card.
