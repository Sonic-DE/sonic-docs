# FormArrow QML Type

An arrow UI component used in Form delegates. [More...](#details)

- Import Statement: import org.kde.kirigamiaddons.formcard

## Detailed Description {#details}

This component can be used to decorate existing or custom Form delegates. It is used, for instance, as the trailing property of [FormButtonDelegate](qml-org-kde-kirigamiaddons-formcard-formbuttondelegate.md).

Each [FormArrow](qml-org-kde-kirigamiaddons-formcard-formarrow.md) instance corresponds to a single arrow that may point upwards, downwards, to the left or to the right.

## Property Documentation {#property-documentation}

### \[default: Qt.RightArrow\] direction : int {#direction-prop}

The direction the [FormArrow](qml-org-kde-kirigamiaddons-formcard-formarrow.md) will point towards.

Set this to any [Qt.ArrowType](https://doc.qt.io/qt-6/qt.html#ArrowType-enum) enum value.
