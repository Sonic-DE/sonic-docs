## Detailed Description {#details}

This component can be used to create your own custom [FormCard](qml-org-kde-kirigamiaddons-formcard-templates-formcard.md) delegates.

By default, it includes a background with hover and click feedback. Set the `background` property to `null` to remove it.

*See also* [FormDelegateBackground](qml-org-kde-kirigamiaddons-formcard-templates-formdelegatebackground.md)
