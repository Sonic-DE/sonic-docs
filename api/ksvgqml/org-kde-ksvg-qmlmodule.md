# KSvg QML Types

A QML module for rendering SVG-based themes with stylesheet re-coloring and on-disk caching.

- [FrameSvg](qml-org-kde-ksvg-framesvg.md)
- [FrameSvgItem](qml-org-kde-ksvg-framesvgitem.md): An SVG Item with borders.
- [ImageSet](qml-org-kde-ksvg-imageset.md)
- [Svg](qml-org-kde-ksvg-svg.md)
- [SvgItem](qml-org-kde-ksvg-svgitem.md): Displays an SVG or an element from an SVG file.
