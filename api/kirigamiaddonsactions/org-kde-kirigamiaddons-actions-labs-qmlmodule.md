# Kirigami Addons Actions (Labs) QML Types

Experimental native menu types for the Kirigami Addons actions module.

- [NativeMenuBar](qml-org-kde-kirigamiaddons-actions-labs-nativemenubar.md): An experimental native menu bar generated from all action collections.
- [NativeMenuItem](qml-org-kde-kirigamiaddons-actions-labs-nativemenuitem.md): An experimental Qt.labs.platform.MenuItem defined by a QAction.
