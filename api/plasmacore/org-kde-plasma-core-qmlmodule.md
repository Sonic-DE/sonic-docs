# Plasma Core QML Types

Plasma Stuff.

- [Action](qml-org-kde-plasma-core-action.md): This class is exposed to wallpapers as the WallpaperItem root qml item.
- [AppletPopup](qml-org-kde-plasma-core-appletpopup.md): Shows a popup for an applet either in the panel or on the desktop.
- [Dialog](qml-org-kde-plasma-core-dialog.md): Creates a Plasma themed top level window that can contain any QML component.
- [PopupPlasmaWindow](qml-org-kde-plasma-core-popupplasmawindow.md): Styled Plasma window that can be positioned relative to an existing Item on another window.
- [ToolTipArea](qml-org-kde-plasma-core-tooltiparea.md): An Item managing a Plasma-themed tooltip.
- [Window](qml-org-kde-plasma-core-window.md): Creates a QQuickWindow themed in a Plasma style with background.
- [WindowThumbnail](qml-org-kde-plasma-core-windowthumbnail.md): Renders a thumbnail for the window specified by the winId property.
