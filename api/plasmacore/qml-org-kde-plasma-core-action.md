### alwaysShowAsMenu : bool {#alwaysShowAsMenu-prop}

Whether this action will be put behind a menu in an applet even if the menu contains only this action. This overrides systray putting single actions behind an button instead of a menu. Useful when it the action's icon cannot be made self-explanatory enough on its own.

Defaults to false.
