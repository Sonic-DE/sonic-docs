# KGuiAddons QML Types

Addons to [QtGui](https://doc.qt.io/qt-6/qtgui-module.html).

- [SystemInhibitor](qml-org-kde-guiaddons-systeminhibitor.md): Inhibit system actions such as logout, suspend, etc.
- [WindowInsetsController](qml-org-kde-guiaddons-windowinsetscontroller.md): Access to window insets colors.
