# KConfig QML Types

Persistent platform-independent application settings.

- [KAuthorized](qml-org-kde-config-kauthorized.md): Singleton used for checking whether actions are allowed by a user.
- [WindowStateSaver](qml-org-kde-config-windowstatesaver.md): Creates a KWindowStateSaver in QML, and assigns it to the window it's parented to.
