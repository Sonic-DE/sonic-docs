# KQuickImageEditor QML Types

QML components providing basic image editing capabilities.

- [AnnotationDocument](qml-org-kde-kquickimageeditor-annotationdocument.md): This class is used to render an image with annotations.
- [AnnotationTool](qml-org-kde-kquickimageeditor-annotationtool.md): The data structure that controls the creation of the next item.
- [AnnotationViewport](qml-org-kde-kquickimageeditor-annotationviewport.md): A QML item which paints its correspondent AnnotationDocument or a sub-part of it, depending from viewportRect and zoom.
- [ImageDocument](qml-org-kde-kquickimageeditor-imagedocument.md): An ImageDocument is the base class of the ImageEditor.
- [ImageItem](qml-org-kde-kquickimageeditor-imageitem.md)
- [QmlPainterPath](qml-org-kde-kquickimageeditor-qmlpainterpath.md): A class for making QPainterPaths available in QML.
- [ResizeHandle](qml-org-kde-kquickimageeditor-resizehandle.md)
- [Utils](qml-org-kde-kquickimageeditor-utils.md)
