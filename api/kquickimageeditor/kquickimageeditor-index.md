# KQuickImageEditor

QML components providing basic image editing capabilities.

## Using the Module {#using-the-module}

Using a Qt module's C++ API requires linking against the module library, either directly or through other dependencies. Several build tools have dedicated support for this, including CMake and [qmake](https://doc.qt.io/qt-6/resources.html#qmake).

### Building with CMake {#building-with-cmake}

To import only the KQuickImageEditor QML modules:

```cpp
ecm_find_qml_module(org.kde.kquickimageeditor REQUIRED)
```

To import KQuickImageEditor into your project using CMake:

```cpp
find_package(KQuickImageEditor REQUIRED)
```
