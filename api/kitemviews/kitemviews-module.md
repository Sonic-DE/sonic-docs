# KItemViews C++ Classes

Set of item views extending the Qt model-view framework. [More...](#details)

## Classes {#classes}

- [KCategorizedSortFilterProxyModel](kcategorizedsortfilterproxymodel.md): This class lets you categorize a view. It is meant to be used along with KCategorizedView class.
- [KCategorizedView](kcategorizedview.md): Item view for listing items in a categorized fashion optionally.
- [KCategoryDrawer](kcategorydrawer.md): The category drawing is performed by this class.
- [KExtendableItemDelegate](kextendableitemdelegate.md): This delegate makes it possible to display an arbitrary QWidget ("extender") that spans all columns below a line of items.
- [KListWidgetSearchLine](klistwidgetsearchline.md): This class makes it easy to add a search line for filtering the items in a listwidget based on a simple text search.
- [KTreeWidgetSearchLine](ktreewidgetsearchline.md): This class makes it easy to add a search line for filtering the items in listviews based on a simple text search.
- [KTreeWidgetSearchLineWidget](ktreewidgetsearchlinewidget.md): Creates a widget featuring a KTreeWidgetSearchLine, a label with the text "Search" and a button to clear the search.
- [KWidgetItemDelegate](kwidgetitemdelegate.md): This class allows to create item delegates embedding simple widgets to interact with items.

## Detailed Description {#details}

[KItemViews](kitemviews-module.md) includes a set of views, which can be used with item models. It includes views for categorizing lists and to add search filters to flat and hierarchical lists.
