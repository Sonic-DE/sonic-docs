# KItemModels QML Types

Models for Qt Model/View system.

- [KColumnHeadersModel](qml-org-kde-kitemmodels-kcolumnheadersmodel.md): Exposes a model's horizontal column headers as a list.
- [KDescendantsProxyModel](qml-org-kde-kitemmodels-kdescendantsproxymodel.md): Flattens a tree model into a list.
- [KNumberModel](qml-org-kde-kitemmodels-knumbermodel.md): Provides a list of numbers at a fixed interval.
- [KRoleNames](qml-org-kde-kitemmodels-krolenames.md): Maps role numbers and names of the attached model.
- [KSortFilterProxyModel](qml-org-kde-kitemmodels-ksortfilterproxymodel.md): Filter and sort an existing QAbstractItemModel.
