# KCoreAddons QML Types

Additions to Qt Core.

- [AboutData](qml-org-kde-coreaddons-aboutdata.md): This type exposes project metadata set with KAboutData from the C++ side.
- [Format](qml-org-kde-coreaddons-format.md): Provides support for formatting numbers and datetimes in formats that are not supported by QLocale.
- [KOSRelease](qml-org-kde-coreaddons-kosrelease.md): Parses /etc/os-release files.
- [KUser](qml-org-kde-coreaddons-kuser.md): User provides read-only access to the user's personal information.
- [Sandbox](qml-org-kde-coreaddons-sandbox.md): Utility functions for use inside application sandboxes such as Flatpak or Snap.
