# AboutData QML Type

This type exposes project metadata set with [KAboutData](../kcoreaddons/kaboutdata.md) from the C++ side. [More...](#details)

- Import Statement: import org.kde.coreaddons

## Detailed Description {#details}

This singleton exposes the following read-only properties:

- [KAboutData::displayName](../kcoreaddons/kaboutdata.md#displayName) as `AboutData.displayName`
- [KAboutData::productName](../kcoreaddons/kaboutdata.md#productName) as `AboutData.productName`
- [KAboutData::componentName](../kcoreaddons/kaboutdata.md#componentName) as `AboutData.componentName`
- [KAboutData::programLogo](../kcoreaddons/kaboutdata.md#programLogo) as `AboutData.programLogo`
- [KAboutData::shortDescription](../kcoreaddons/kaboutdata.md#shortDescription) as `AboutData.shortDescription`
- [KAboutData::homepage](../kcoreaddons/kaboutdata.md#homepage) as `AboutData.homepage`
- [KAboutData::bugAddress](../kcoreaddons/kaboutdata.md#bugAddress) as `AboutData.bugAddress`
- [KAboutData::version](../kcoreaddons/kaboutdata.md#version) as `AboutData.version`
- [KAboutData::otherText](../kcoreaddons/kaboutdata.md#otherText) as `AboutData.otherText`
- [KAboutData::authors](../kcoreaddons/kaboutdata.md#authors) as `AboutData.authors`
- [KAboutData::credits](../kcoreaddons/kaboutdata.md#credits) as `AboutData.credits`
- [KAboutData::translators](../kcoreaddons/kaboutdata.md#translators) as `AboutData.translators`
- [KAboutData::components](../kcoreaddons/kaboutdata.md#components) as `AboutData.components`
- [KAboutData::licenses](../kcoreaddons/kaboutdata.md#licenses) as `AboutData.licenses`
- [KAboutData::copyrightStatement](../kcoreaddons/kaboutdata.md#copyrightStatement) as `AboutData.copyrightStatement`
- [KAboutData::desktopFileName](../kcoreaddons/kaboutdata.md#desktopFileName) as `AboutData.desktopFileName`

The [KAboutData](../kcoreaddons/kaboutdata.md) metadata is expected to be set in C++ (or equivalent [KAboutData](../kcoreaddons/kaboutdata.md) bindings).

*See also* [KAboutData](../kcoreaddons/kaboutdata.md)
