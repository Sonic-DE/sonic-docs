# KItemModels C++ Classes

Models for Qt Model/View system. [More...](#details)

## Classes {#classes}

- [KBreadcrumbSelectionModel](kbreadcrumbselectionmodel.md): Selects the parents of selected items to create breadcrumbs.
- [KCheckableProxyModel](kcheckableproxymodel.md): Adds a checkable capability to a source model
- [KColumnHeadersModel](kcolumnheadersmodel.md): A model that converts a model's headers into a list model.
- [KDescendantsProxyModel](kdescendantsproxymodel.md): Proxy Model for restructuring a Tree into a list.
- [KExtraColumnsProxyModel](kextracolumnsproxymodel.md): This proxy appends extra columns (after all existing columns).
- [KLinkItemSelectionModel](klinkitemselectionmodel.md): Makes it possible to share a selection in multiple views which do not have the same source model.
- [KModelIndexProxyMapper](kmodelindexproxymapper.md): This class facilitates easy mapping of indexes and selections through proxy models.
- [KNumberModel](knumbermodel.md): Creates a model of entries from N to M with rows at a given interval.
- [KRearrangeColumnsProxyModel](krearrangecolumnsproxymodel.md): This proxy shows specific columns from the source model, in any order.
- [KSelectionProxyModel](kselectionproxymodel.md): A Proxy Model which presents a subset of its source model to observers.
