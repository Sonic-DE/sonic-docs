# KNightTime C++ Classes

Helpers for scheduling the dark-light cycle. [More...](#details)

## Classes {#classes}

- [KDarkLightCycle](kdarklightcycle.md): The KDarkLightCycle provides information about the light-dark cycle for a single day.
- [KDarkLightSchedule](kdarklightschedule.md): The KDarkLightSchedule type represents a schedule for the dark-light cycle.
- [KDarkLightScheduleProvider](kdarklightscheduleprovider.md): The KDarkLightScheduleProvider provides a convenient way to retrieve the schedule of the dark-light cycle.
- [KDarkLightTransition](kdarklighttransition.md): The KDarkLightTransition type represents a transition from day to night or vice versa.

## Detailed Description {#details}

This library provides a C++ API that provides information about the times of the dark-light cycle. It can be used to implement such as adjusting the screen color temperature depending on time of day, etc.
