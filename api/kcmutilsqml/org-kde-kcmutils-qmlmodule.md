# KCMUtils QML Types

QML types for creating config modules.

- [AbstractKCM](qml-org-kde-kcmutils-abstractkcm.md): This component is intended to be used as root item for KCMs with arbitrary content.
- [GridDelegate](qml-org-kde-kcmutils-griddelegate.md): Base delegate for KControlmodules based on Grid views of thumbnails.
- [GridView](qml-org-kde-kcmutils-gridview.md): A ScrollView containing a GridView, with the default behavior about sizing and background as recommended by the user interface guidelines.
- [GridViewKCM](qml-org-kde-kcmutils-gridviewkcm.md): This component is intended to be used as the root item for KCMs that are based upon a grid view of thumbnails, such as the theme or wallpaper selectors.
- [KCMLauncher](qml-org-kde-kcmutils-kcmlauncher.md)
- [PluginDelegate](qml-org-kde-kcmutils-plugindelegate.md)
- [PluginSelector](qml-org-kde-kcmutils-pluginselector.md): ListView for showing plugins with their info and configuration.
- [ScrollView](qml-org-kde-kcmutils-scrollview.md): A ScrollView containing a GridView, with the default behavior about sizing and background as recommended by the user interface guidelines.
- [ScrollViewKCM](qml-org-kde-kcmutils-scrollviewkcm.md): This component is intended to be used as the root item for KCMs that are based upon a list view or another vertical flickable.
- [SettingHighlighter](qml-org-kde-kcmutils-settinghighlighter.md): SettingHighlighter automatically impacts the representation of an item based on the value of a setting.
- [SettingStateBinding](qml-org-kde-kcmutils-settingstatebinding.md): SettingStateBinding automatically impacts the representation of an item based on the state of a setting.
- [SettingStateProxy](qml-org-kde-kcmutils-settingstateproxy.md): Allows to represent the state of a particular setting in a config object in a declarative way.
- [SimpleKCM](qml-org-kde-kcmutils-simplekcm.md): This component is intended to be used as root item for KCMs with arbitrary content.
